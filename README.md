# Cosmo Box

Личный медиасервер «в коробке» — фильмы и сериалы из ваших папок, без
внешних сервисов. Строго локальный: приложение работает у вас на машине
и наружу не смотрит.

Это репозиторий **распространения и автообновлений** десктопного
приложения Cosmo Box. Здесь публикуются установщики и подписанный
манифест обновления — исходный код в этот репозиторий не входит.

## Установка

Скачайте установщик из последнего релиза и запустите его:

**→ [Последний релиз](https://github.com/cossackgh/cosmobox-releases/releases/latest)**

- Платформа: **Windows (x64)**.
- Установщик самодостаточен — ничего доустанавливать не нужно.

## Обновления

Приложение обновляется само: при запуске сверяется с последним релизом
в этом репозитории и предлагает обновиться. Можно проверить и вручную —
**Настройки → Обновления → Проверить обновления**. Пакеты обновлений
подписаны, приложение проверяет подпись перед установкой.

## Использование

После установки: укажите папки с медиа → приложение просканирует их и
подтянет обложки и описания (из локальных NFO или, по желанию, из TMDB по
вашему ключу) → смотрите.

# Cosmo Box

A personal, self-contained media server — your own movies and TV shows
from your own folders, with no external services required. Strictly
local: the app runs on your machine and does not reach out.

This is the **distribution and auto-update** repository for the Cosmo Box
desktop app. It hosts the installers and the signed update manifest — the
application source code is not part of this repository.

## Install

Download the installer from the latest release and run it:

**→ [Latest release](https://github.com/cossackgh/cosmobox-releases/releases/latest)**

- Platform: **Windows (x64)**.
- The installer is self-contained — nothing else to install.

## Updates

The app updates itself: on launch it checks the latest release in this
repository and offers to update. You can also check manually —
**Settings → Updates → Check for updates**. Update packages are signed,
and the app verifies the signature before installing.

## Usage

After installing: point the app at your media folders → it scans them and
pulls in posters and descriptions (from local NFO files or, optionally,
from TMDB with your own key) → watch.
